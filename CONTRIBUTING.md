# Contributing

DevGuide AI is currently being bootstrapped. Discuss technology or scope changes before adding application code.

## Workflow

1. Create a focused branch.
2. Keep changes aligned with `PRD.md` and `architecture.md`.
3. Add or update tests and documentation with implementation changes.
4. Run the checks exposed by `make check` once they are implemented.
5. Open a pull request describing scope, validation, risks, and unresolved TODOs.

## Standards

- Do not commit credentials, tokens, private repository data, or generated secrets.
- Use clear commit messages and small, reviewable changes.
- Document architectural decisions in `docs/decisions`.
- Do not claim planned features are complete.
